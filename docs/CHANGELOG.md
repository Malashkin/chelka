# Changelog

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).

## [Unreleased]

### Fixed
- Мигание полки при наведении на чёлку: во время анимации кадра AppKit шлёт
  ложные mouseExited (пересоздание tracking-зон при resize окна под курсором),
  полка сворачивалась/раскрывалась по кругу. Теперь сворачивание — только
  если курсор реально вне окна.

### Changed
- Иконка приложения без белых полей: плитка вырезана из арта, углы
  прозрачные (scripts/make-icon.swift, исходник — Resources/icon-art.jpg).
- Геометрия панели и прогресс анимации вынесены в `ChelkaCore.ShelfGeometry`
  (чистые функции) и покрыты тестами; selftest вырос с 6 до 27 проверок.

### Added
- Подготовка к open source: README на английском с двумя инструкциями
  установки (один Mac / два Mac через Tailscale), русская версия README.ru.md,
  лицензия MIT. Личные хостнеймы из README убраны.
- Превью содержимого на полке: картинки (а также PDF и видео) показываются
  миниатюрой через QuickLookThumbnailing, с сохранением пропорций и
  скруглением; миниатюра же — под курсором при drag-and-drop.
- Иконка приложения: лоб с чёлкой на фоне ковра (Resources/AppIcon-1024.png,
  .icns собирается в make-app.sh).
- README.md: полное описание, быстрый старт, настройка второй машины,
  таблица проблем и решений.
- Плавные анимации полки: выезд из чёлки с ease-out (NSAnimationContext),
  контент растёт и проявляется вместе с окном (прогресс от текущей высоты).
- `make install` (в /Applications, перезапуск через Spotlight) и пункт меню
  «Запускать при входе» (SMAppService).
- MVP приложения Chelka: панель над чёлкой (приём и отдача drag-and-drop),
  папка-полка `~/Shelf` с watcher'ом, push на удалённую машину через
  rsync/ssh (Tailscale), статусы доставки, контекстное меню, fallback-полка
  для экранов без чёлки. Сборка `.app` — `make app`, тесты — `make test`
  (selftest-таргет: без Xcode нет XCTest/Testing).
- ADR-0001: архитектура полки в чёлке с синхронизацией на Mac mini через
  Tailscale (синхронизируемая папка-полка, push-only, rsync/SSH как MVP-транспорт).
