## [0.1.0] — 2026-09-18

Первый публичный релиз.

### Added

- **Полка в чёлке**: приём файлов drag-and-drop'ом, отдача drag'ом обратно
  (в Telegram — вложением), плавные анимации выезда из чёлки, превью
  содержимого для картинок/PDF/видео (QuickLook), контекстное меню (убрать
  в Корзину, показать в Finder, отправить на пира, автозапуск при входе),
  fallback-полоска для экранов без чёлки.
- **Синхронизация на второй Mac через Tailscale**: rsync поверх ssh,
  push-only с ретраями и статусами доставки на иконках; двусторонняя при
  зеркальной настройке; петля исключена архитектурно (пушится только
  задропленное на этой машине).
- **Безопасность** (по результатам аудита, [security/](security/index.md)):
  валидация `peerHost` до попадания в аргументы ssh/rsync; транспортный ключ
  зажат forced-command-обёрткой (только приём в `~/Shelf`);
  `StrictHostKeyChecking=yes` с пиннингом на `ssh-copy-id`; quarantine на
  прилетевшие файлы; `--ignore-existing` против перезаписи на приёмнике.
- **Тесты**: selftest-таргет на 66 проверок (работает без Xcode) — имена,
  геометрия, превью, валидация peerHost, обёртка ключа, логика карантина.
- **Инфраструктура**: `make build/test/app/run/install/deploy`, генерация
  иконки по сетке macOS, README (EN/RU), AGENTS.md для ИИ-агентов, MIT.
