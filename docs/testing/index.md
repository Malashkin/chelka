# Тестирование

## Стратегия

На машине нет полного Xcode (только CLT) → XCTest и Swift Testing недоступны.
Тесты чистой логики живут в исполняемом таргете `lintel-selftest`
(`make test`), падение проверки — ненулевой exit-код.

Покрытые риски (173 проверки):

- **Инъекция через peerHost** (`PeerHost.isValid`): значение из настроек
  попадает в аргументы ssh/rsync — 17 кейсов на опции, shell-метасимволы,
  переводы строк, двойной @, длину. Промах = выполнение команд.
- **Обёртка транспортного ключа** (`scripts/lintel-receive.sh`, гоняется как
  процесс с подставным SSH_ORIGINAL_COMMAND): 12 кейсов (включая старое имя
  `chelka-clear` для пиров на сборке до переименования) — shell/команды/
  `--sender`/запись мимо Shelf/ и метасимволы отклоняются, законные
  mkdir и приём rsync проходят. Промах = полный shell по транспортному ключу.
- **Транспортные аргументы** (`PushPlan`): '--' перед хостом, mkdir только
  Shelf, --ignore-existing, StrictHostKeyChecking=yes, BatchMode — общие для
  приложения и MCP-сервера. **Имена с полки** (`ShelfName.isSafe`): path
  traversal, скрытые файлы, разделители — отклоняются (операции MCP по имени).
- **Автоочистка** (`Sync.updatedSeen`/`expired`): возраст от появления на
  полке, ровно N дней ещё не просрочен, retentionDays 0 выключает; боевой
  прогон lintel-clear на подставном HOME (файлы уезжают в Корзину).
- **Сетка файлов на полке** (`ShelfLayout` + `ShelfGeometry.expandedRect(content:)`):
  29 кейсов — перенос строк после 8 колонок, 3 видимые строки, диапазон и
  границы прокрутки, каждый из 30 файлов достижим скроллом, центрирование
  короткой строки, рост окна под сетку и не шире экрана, деление на ноль в
  прогрессе. Мутанты «нет прокрутки», «нет переноса строк», «скролл без
  верхней границы» — убиты. Промах = файлы на полке есть, а увидеть/вытащить
  их нельзя (исходный баг: видно только первые 5).
- **Нижняя строка полки** (`ShelfSummary`, `ShelfLayout.footerRect`/`openButtonRect`):
  39 кейсов — русское число (1/3/5/11/12/21/104/111), формат размера (граница
  1000, «1,5 МБ», 999,6 КБ → «1 МБ», 9,96 МБ → «10 МБ»), реальный подсчёт на
  временной папке (рекурсия, скрытое внутри, симлинк не разыменовывается,
  пропавший файл), кнопка внутри строки и полки, ячейки на неё не налезают.
  Мутанты «11 → файл», «нет перехода к след. единице», «нет рекурсии» убиты;
  «считать размер самих каталогов» выжил — эквивалентен (APFS не отдаёт
  fileSize для каталогов, прибавляется 0).
- **Перенос настроек со старого имени** (`Settings.migrate`/`string`): 9 кейсов —
  переносятся только отсутствующие ключи, новые значения не перезаписываются,
  перенос однократный (удалённый ключ не воскресает), старый домен не тронут,
  чтение падает на старый домен. Тесты работают на временных доменах
  `dev.mike.lintel-selftest.*` и удаляют их. Мутационная проверка: снятие
  фильтра «только отсутствующие» и метки однократности — оба мутанта убиты.
  Промах = потерянный peerHost после обновления или «воскресшие» настройки.
- **Карантин новоприбывших** (`Sync.newcomers`): 4 кейса — файл извне метится,
  локальный дроп нет, первый скан без состояния никого не метит.
  Промах = вредонос с пира мимо Gatekeeper или карантин на своих файлах.
- **Коллизии имён при дропе** (`Naming.uniqueName`): перезапись/потеря файла на
  полке. Кейсы: без коллизии, суффикс перед расширением, цепочка `-1/-2/-3`,
  имя без расширения, несколько точек (`.tar.gz`), пробелы и кириллица.
- **Геометрия панели** (`ShelfGeometry`): hit-зона шире чёлки на `hitSlop` с
  каждой стороны, панель прижата к верхней кромке, fallback-полоска по центру
  ниже кромки на настраиваемый отступ (в т.ч. при нулевом `safeTop`;
  полка раскрывается от полоски), раскрытая полка не уже
  минимума и по центру экрана. Промах здесь = в полку нельзя попасть курсором.
- **Прогресс анимации** (`expandProgress`/`contentAlpha`): клампинг 0…1,
  контент проявляется во второй половине. Промах = мигание или невидимый контент.

Не покрыто автоматикой (проверяется руками, см. чек-лист):

- AppKit-слой: drag-and-drop, геометрия чёлки, расширение панели — требует
  живого WindowServer и реального drag'а.
- Transport: требует живого пира по ssh.

## Ручной чек-лист MVP

1. `make run` → навести курсор на чёлку → полка раскрывается, «Бросьте файлы сюда».
2. Перетащить файл из Finder на чёлку → файл появился на полке и в `~/Shelf`.
3. Вытащить файл с полки в окно Telegram → становится вложением.
4. С настроенным `peerHost`: после дропа файл появляется в `~/Shelf` на mini,
   на иконке оранжевая → зелёная точка.
5. Выключить Wi-Fi, задропить файл → после 5 попыток красная точка;
   правая кнопка → «Отправить ещё раз» после восстановления сети.
6. Положить на полку 30+ файлов (`cp` в `~/Shelf`) → полка раскрывается
   сеткой 8×3, справа ползунок; прокрутка трекпадом/колесом доходит до самых
   старых; наполовину прокрученный файл под чёлкой не ловит клик; после
   сворачивания и повторного раскрытия — снова с начала.
7. Внизу раскрытой полки — «N файлов · размер», совпадает с Finder
   (⌘I на `~/Shelf`, с точностью до округления); бросить большую папку — сначала
   старое значение, затем новое, UI не подвисает. Кнопка «Открыть папку»
   открывает `~/Shelf` в Finder по отпусканию; увёл курсор с зажатой кнопки —
   не открывает.
