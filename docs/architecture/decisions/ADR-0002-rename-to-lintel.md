# ADR-0002: Переименование Chelka → Lintel

Статус: принято · Дата: 2026-11-12

## Контекст

Название «Chelka» (транслит «чёлка» — русское прозвище выреза экрана MacBook)
понятно только русскоязычным, а иконка (лоб с чёлкой на фоне ковра) держалась
на этой шутке. Для англоязычной аудитории нужно имя, которое не требует
объяснений про русский сленг.

## Рассмотренные варианты

| Имя | Почему нет / да |
|---|---|
| Notch Shelf | Занято: open-source приложение с той же функцией (notchshelf.pages.dev). |
| Ledge | Занято в той же категории: платное Mac-приложение «буфер + полка» и Electron-полка olllayor/ledge. |
| Notch Relay | Конфликтов не найдено; отвергнуто владельцем в пользу Lintel. |
| **Lintel** | Конфликтов среди Mac-полок не найдено. «Перемычка над проёмом» — полка прямо под вырезом. |

Проверка — веб-поиск на 2026-11-12, не юридическая проверка товарного знака.

## Решение

Переименовать всё: бандл (`Lintel.app`, `dev.mike.Lintel`), SwiftPM-таргеты
(`Lintel`, `LintelCore`, `lintel-mcp`, `lintel-selftest`), обёртку
(`scripts/lintel-receive.sh`), команду очистки (`lintel-clear`), имя MCP-сервера,
документацию. Иконка рисуется кодом (`scripts/make-icon.swift`): вырез экрана,
под ним полка с тремя файлами и зелёной точкой «доставлено».

Совместимость с уже развёрнутым:

- **Настройки**: `Settings.migrate` при первом запуске копирует ключи из
  `dev.mike.Chelka` в `dev.mike.Lintel` — только отсутствующие, однократно
  (метка `migratedFromChelka`), старый домен не удаляется (откат возможен).
  MCP-сервер читает `peerHost` из нового домена с откатом на старый.
- **Обёртка на приёмнике**: принимает и `lintel-clear`, и `chelka-clear` —
  пир со старой сборкой продолжает чистить полку. Обратное не работает:
  старая обёртка не знает `lintel-clear` — отсюда ручной шаг «обновить обёртку».
- **SSH-ключ и путь обёртки** не переименовываются у существующих установок:
  это просто имена файлов в `~/.ssh/config` и `authorized_keys`.
- **`make install` / `make deploy`** удаляют старый `Chelka.app`.

## Последствия

- Автозапуск (`SMAppService.mainApp`) привязан к бандлу — включается заново.
- MCP-сервер нужно перерегистрировать по новому пути.
- Промо-креативы со старым именем удалены из `docs/promo`; новые не сделаны.
- Записи в CHANGELOG до переименования оставлены со старым именем — это история.
- Репозиторий на GitHub пока называется `chelka`; переименование — отдельное
  решение владельца (GitHub оставляет редирект со старого адреса).
